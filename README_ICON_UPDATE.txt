A-CHECK V1.13.3 ショートカットアイコン更新版
V1.13.2ヘッダー修正版を基準に、採用済みの紫のアイコンを組み込んだ一式です。
点検機能、写真、バックアップ形式、保存キー、アプリ内ヘッダーのアイコンは維持しています。
更新内容：タブ用・ホーム画面用アイコン、バージョン表示、キャッシュ更新。

【更新前】
現在のA-CHECKの「全データを書き出す」でバックアップを保存してください。
端末の点検データは、GitHubへアップロードするアプリファイルには含まれていません。

【GitHub Pagesへの更新】
1. ZIPをPCで解凍します。
2. 現在使用中のリポジトリ takuzof/junkai- を開きます。
3. Add file → Upload files。
4. ZIP内のHTML、manifest、service-worker、SVG、PNG、ICOをすべてアップロードします。
   README_ICON_UPDATE.txtはアップロード不要です。
   ZIPそのものや、解凍したフォルダをそのまま追加するのではなく、中のファイルを直下へ置きます。
5. mainへCommitします。同名ファイルは上書きします。
6. Pagesに反映後、iPhoneのSafariで現在と同じ https://takuzof.github.io/junkai-/ を開きます。
7. 画面右側がV1.13.3になっていることを確認します。
   古いままなら再読み込みし、一度閉じて同じURLを開き直してください。

【iPhoneのホーム画面アイコン】
既存アイコンが新しくなるとは限らないため、古い場合は次の手順です。
1. Safariから同じURLを開き、物件・巡回履歴が見えるか確認します。
2. ホーム画面の古いA-CHECKショートカットを取り除きます。
3. Safariの共有 → ホーム画面に追加。
4. 紫のチェックボードのアイコンで追加できるか確認します。

重要：Safariの「履歴とWebサイトデータを消去」などは実行しないでください。
バックアップを取る前にホーム画面版を削除しないでください。
Safari版とホーム画面版で保存状態が異なる場合は、両方のバックアップを先に保存します。
今回、端末データを削除する処理は追加していません。
URL・ドメイン・リポジトリを変更せず、現在の公開先へ上書きしてください。
